# agentctl 0.25.2

- The board highlights the entire selected row, including task states, queue entries, pulled cohort headers and WALL lists. Truecolor and 256-color terminals show bold white on dark blue by default. Terminals with 16 colors use bold reverse video. Monochrome and `NO_COLOR` use reverse video.
- In a split view, Tab or the Left and Right arrows switch focus. The selected row dims while the preview has focus. Configure the selection in `board.selection` with `bg`, `fg`, `bold` and `style`. Doctor validates the settings. [Configuration](../en/configuration.md)

For a clone installation, upgrade after the tag is available in the source repository.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.25.2
agentctl board --tmux --restart
agentctl doctor
```
