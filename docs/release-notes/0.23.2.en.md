# agentctl 0.23.2

- **WALL-23** fixes MCP `send` registering a follow-up on its first call. The preview shows the exact text, screen state and current input field when readable. A busy pane shows that the message will be queued until the turn ends if the agent is still busy when the confirmed send is applied. This applies to local and SSH-hosted tasks.
- Review the preview, then send `confirm: true` with its `preview_token` in the same MCP session. `send` with `withdraw` and single-task `mark` now use this flow, too. `send` with `enter_only` and `answer` still check the exact draft or current menu.
- The `gc` write tool returns a preview before creating a request. Use the read tool `gc_preview` to ask watch to prepare a remote GC plan when needed.
- The upgraded watcher refuses pending sends and marks recorded by the former one-step paths. Preview and confirm them again if they are still needed.

For a clone-based installation, run:

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.23.2
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Quit Claude Desktop with **⌘Q** and reopen it to reload the MCP server. Keep the task windows open.
