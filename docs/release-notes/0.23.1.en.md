See [host setup and the first real PC test](../en/hosts.md), [configuration](../en/configuration.md), and [CHANGELOG](../../CHANGELOG.md). Remote GC never forces deletion; it keeps reports, symlinks, shared/linked/protected/dirty/unpushed worktrees, and uses bounded host measurements. Remote cache references are conservative; ambiguity retains data. Cached host admission requires a sample ≤60 s old; actual setup reads fresh filesystem counters on that host, using an existing ancestor for a new work_dir. Snapshot reads do not substitute dispatcher disk values for remote volumes.

Validation uses fake SSH/tmux/providers, without inference or network. The real PC smoke is still an owner action. Automatic remote review remains a separately ordered task (`review: false`). Host credential presence is only a best-effort login signal.

## Owner publication and upgrade

Use the full release commit SHA from REL0244.md in place of `<sha>`. These commands are for the owner.

```sh
cd ~/Projects/agentctl
git push origin <sha>:main
git push origin v0.22.5 v0.22.6 v0.22.7 v0.22.8 v0.23.1
gh release create v0.23.1 --draft --title 'agentctl 0.23.1' --notes-file docs/release-notes/0.23.1.en.md
```

A tag push runs CI; a draft Release does not publish npm. **Publishing the GitHub Release** triggers `.github/workflows/publish.yml`: matching stable tag/package check, install/tests/typecheck/build and OIDC `npm publish --provenance --access public` if the version is absent. Removing `--draft` from `gh release create v0.23.1` publishes immediately and starts that workflow.

For the clone-based production installation:

```sh
cd ~
cp ~/.agentctl/config.yaml ~/.agentctl/config.yaml.pre-0.23.1-$(date +%Y%m%d-%H%M%S)
~/Projects/agentctl/bin/agentctl-update --ref v0.23.1
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Quit Claude Desktop with **⌘Q**, then reopen it so its MCP process loads the updated code. Keep active task windows; restarting watch/board does not require restarting agents.

For the dev instance, run `~/Projects/agentctl/bin/agentctl-dev-update v0.23.1`. It rebuilds `~/Projects/agentctl-wt/devtest` using `~/.agentctl-dev` and restarts dev watch/board. Use `--status` to inspect it, `--rollback` to rebuild the previous commit, `--no-restart` to skip restarts, or `--skip-ci` to reuse dependencies. Quit and reopen Claude Desktop to reload the dev MCP server.

Preserve existing queue/board/disk settings and `mcp.allow`; add `pin` only if chats should be allowed to change pin state. Adjust host PATH to include the installed Node/provider binaries. Default peak scheduling needs no new key; override `providers_config.glm.peak` only deliberately.

First verify `ssh -p 2222 krzet@192.168.2.64`, fingerprint and BatchMode access, then follow the host guide's WSL2 setup and **PC-SMOKE-1** spec. Run `agentctl hosts --refresh`, `agentctl watch --tmux`, `agentctl new pc-smoke.md --no-wait-trust`, approve folder trust through the printed `agentctl attach PC-SMOKE-1` SSH command, then check board H and `agentctl pull PC-SMOKE-1`; close it and preview GC. This is the first real remote/provider test, not part of automated release validation.
