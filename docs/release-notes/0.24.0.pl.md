# agentctl 0.24.0

- `setup.node_modules: clone` pozwala wykorzystać zgodną instalację `npm ci` w kolejnych worktree. APFS korzysta z niezależnych klonów copy-on-write, a Linux z reflinków na obsługujących je systemach plików. `status` i `capacity` pokazują rozmiar magazynu oraz liczniki użyć, a `gc` przenosi stare wpisy do kosza po zatwierdzeniu.
- `close.cleanup` po zamknięciu zadania przenosi wybrane pliki ignorowane przez Git do kosza. Dziennik zapisuje każdą przeniesioną ścieżkę i jej rozmiar.
- `worktrees.root` może wskazywać dysk zewnętrzny. Dla niestandardowej ścieżki podaj `worktrees.mount`. Brak woluminu blokuje setup i wysyła jedno powiadomienie. Po zamontowaniu użyj `agentctl unblock TASK`. Zobacz [oszczędzanie miejsca na dysku](../pl/tutorial.md#oszczędzanie-miejsca-na-dysku), także dla hostów SSH.

W instalacji z klona uruchom poniższe polecenia po udostępnieniu taga w repozytorium źródłowym:

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.24.0
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Zamknij Claude Desktop przez **⌘Q** i uruchom ponownie, aby przeładować MCP. Okna zadań mogą zostać otwarte.
