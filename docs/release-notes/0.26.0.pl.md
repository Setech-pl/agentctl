# agentctl 0.26.0

- `setup: {from_task: NC-42}` klonuje zgodne zależności lokalnego zadania metodą copy-on-write. Przegląd ma własne worktree i korzysta ze zwykłego setup, gdy klon jest niedostępny.
- `review: {mode: readonly-on-author}` otwiera przegląd w lokalnym worktree zatrzymanego autora. Hooki procesu recenzenta blokują zwykłe commity i push, a dowody trafiają pod cache.
- `merge_base_check: warn`, `block` lub `candidate` sprawdza aktualność przeglądu względem lokalnego `main` lub `master`. Konflikt kandydata blokuje start i pokazuje ścieżki.
- Po lokalnej integracji watch proponuje GC i przekazuje czatom właścicieli wiadomość WALL z rozmiarem i ID żądania. Usuwanie wymaga potwierdzenia. `gc: {after_integration: off}` wyłącza propozycje.
- `close` zamyka zadanie także po zniknięciu okna i rozpoznaje dokładne ID zamkniętego zadania.

[Przeglądy i integracje bez zapełniania dysku](../pl/tutorial.md#przeglądy-i-integracje-bez-zapełniania-dysku)

Zaktualizuj instalację z klonu, gdy tag wydania będzie w nim dostępny.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.26.0
agentctl doctor
```
