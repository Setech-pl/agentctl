# agentctl 0.25.3

- Watch validates and starts queued work even when a full status sweep takes longer than its watchdog deadline. The board and doctor show the skipped step and when it began. A completed slow sweep is reused on the next tick.
- Queued Codex messages can be sent once watch confirms that the composer is empty, even while background terminals continue running.
- After disk space returns, watch retries state and snapshot writes and records one `zapis stanu wznowiony` event. A temporary write error no longer leaves the task looking as if it still needs attention. An MCP response timeout cannot interrupt a state commit once it starts.
- With watch running, MCP `gc` hands planning to watch and returns a `request_id`. Poll `gc` with that ID to review the plan and get its `preview_token`. Confirm with that token and `confirm: true`. Watch checks the reviewed scope again before applying it.
- The CLI accepts `gc --force-dirty TASK [TASK...]`. To authorize all eligible local worktrees in the selection, use `--force-dirty-all`. Applying that plan prints dirty-file and unpushed-commit counts and requires y/N on a terminal, even with `--yes`.
- Board disk severity and colour follow fresh free space. The worktree estimate and its age are informational.
- Watch posts global limit and quota changes once on WALL channel `agentctl`, with old and new values and the source. It marks its own long-wait decision requests `answered` when the wait ends or `superseded` when the task closes or is cancelled. The reason appears in the WALL history.

For a clone installation, upgrade after the tag is available in the source repository.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.25.3
agentctl doctor
```
