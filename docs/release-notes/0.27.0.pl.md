# agentctl 0.27.0

- MCP `set_limits` domyślnie składa wniosek ważny dwie godziny. Właściciel dostaje powiadomienie na pulpicie i wniosek na WALL. Decyzję podejmuje przez `L` na tablicy albo `agentctl limits approve ID` / `reject ID`. Czasowe wstrzymanie dostawcy nadal działa bezpośrednio.
- Kwoty czatów podążają za limitami globalnymi według udziałów procentowych i mnożnika `overprovision`. Przy migracji z 0.25 można zachować sztywne nadpisania dla wybranych dostawców.
- Przełączaj profile przez `agentctl limits profile night` lub z tablicy. Harmonogram przyjmuje godziny lokalne i strefę IANA. `limits set claude=10 --until 23:00` po wygaśnięciu przywraca limit aktualnego profilu.
- Po zastosowaniu zmian WALL `agentctl` pokazuje porównanie wartości, źródło i efektywne pułapy czatów.

[Limity dla kilku czatów i migracja](../pl/tutorial.md#limity-dla-kilku-czatów)

Zaktualizuj instalację z klonu, gdy tag wydania jest dostępny w tym klonie.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.27.0
agentctl doctor
```
