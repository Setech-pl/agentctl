# agentctl 0.25.2

- Board zaznacza cały wiersz zadania, pozycji kolejki, nagłówka odebranej kohorty lub listy WALL. Terminale z truecolor i 256 kolorami domyślnie pokazują biały pogrubiony tekst na ciemnoniebieskim tle. Terminal z 16 kolorami odwraca kolory i pogrubia tekst. Tryb monochromatyczny i `NO_COLOR` odwracają kolory.
- W widoku dzielonym Tab oraz strzałki w lewo i w prawo przełączają aktywny panel. Zaznaczony wiersz przygasa, gdy aktywny jest podgląd. Styl można zmienić w `board.selection` polami `bg`, `fg`, `bold` oraz `style`. Doctor sprawdza te ustawienia. [Konfiguracja](../pl/configuration.md)

Jeśli korzystasz z klonu repozytorium, zaktualizuj instalację po udostępnieniu tagu w repozytorium źródłowym.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.25.2
agentctl board --tmux --restart
agentctl doctor
```
