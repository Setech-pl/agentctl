# agentctl 0.24.0

- `setup.node_modules: clone` reuses compatible `npm ci` installs through independent copy-on-write clones on APFS and reflink copies where Linux supports them. Status and capacity show store size and hit/miss counters. GC previews stale entries and sends them to Trash on apply.
- `close.cleanup` sends configured, Git-ignored worktree output to Trash after a task closes. The event records each moved path and its size.
- `worktrees.root` supports an external volume. Use `worktrees.mount` for a custom mount location. A missing volume blocks setup with one notification. After remounting, run `agentctl unblock TASK` to resume the queued start. See the [disk-space tutorial](../en/tutorial.md#saving-disk-space) for setup and SSH support.

For a clone installation, after the release tag is available in your source repository, run:

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.24.0
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Quit Claude Desktop with **⌘Q** and reopen it to reload MCP. Task windows can stay open.
