# agentctl 0.27.3

Use a Mac dispatcher with a Windows PC running Ubuntu WSL. Automatic placement shares capacity across the machines, honours owner reservations and keeps related worktrees together. Fetch-only branch sync gives the Mac access to worker results. Exclusive perf orders carry builds to the PC and measurements back. Configure SSH and both provider logins with the [two-machine setup](../en/hosts.md#two-machines-mac--pcwsl).

- **Remote host placement.** Order with `host: auto`, or route chats and cohorts with `placement.chats` / `placement.cohorts`. Placement checks the account slot, host limits, the repository clone, provider login, a health sample from the last minute, the work volume, load and availability. Related worktrees win; ties go to the host with fewer running tasks, then `placement.prefer`. An offline eligible worker holds local fallback for `placement.failover_after`.
- **Branch fetch-back.** Watch fetches the task branch from the worker into the Mac clone when the worker reports and at close. A checked-out or divergent branch keeps its local ref; the worker head stays at `refs/remotes/<host>/<branch>` and the journal records the conflict. `sync: off` disables it.
- **PC availability.** `hosts.<name>.availability` reserves a machine by time windows (which may cross midnight), busy processes or GPU load, with `yield: stop-new` or `pause-all`. `agentctl hosts pause pc --until 3h` and `agentctl hosts resume pc` (MCP `hosts_pause` / `hosts_resume`, board `H`) set a manual reservation.
- **Perf on a host.** `class: perf` reserves the worker exclusively when due, transfers a bounded build to it and the measurement results back.
- Includes everything in 0.27.2.

**Upgrade note:** nothing moves to the PC by itself. `placement.default` stays `local` unless you configure it; without `host:` in a spec or a matching `placement` rule, tasks keep running on the Mac. `queue.hold_on_load` still governs whether load holds local starts.

Upgrade a clone installation once the release tag is available in that clone.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.27.3
agentctl doctor
```
