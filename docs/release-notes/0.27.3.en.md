# agentctl 0.27.3

Use a Mac dispatcher with a Windows PC running Ubuntu WSL. Automatic placement shares capacity across the machines, honours owner reservations and keeps related worktrees together. Fetch-only branch sync gives the Mac access to worker results. Exclusive perf orders carry builds to the PC and measurements back. Configure SSH and both provider logins with the [two-machine setup](../en/hosts.md#two-machines-mac--pcwsl).
