# agentctl 0.25.1

- Watch zapisuje alert planu we wspólnym stanie przed wysłaniem go na pulpit lub telefon. Dla danego dostawcy, okna planu, progu i okresu resetu wysyła go raz, także po restarcie, chwilowym braku odczytu i drobnej korekcie czasu resetu.
- Status MCP pokazuje jeden wiersz o zmianie pojemności raz w każdej sesji czatu. Alert o wyczerpaniu limitu wysyła watch, a hook nadal od razu wstrzymuje uruchamianie zadań u danego dostawcy. Watch zapisuje stan zaufania, dysku i obciążenia przed ogłoszeniem zmiany.

W instalacji z klona zaktualizuj program po udostępnieniu tagu w repozytorium źródłowym.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.25.1
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Zamknij Claude Desktop przez **⌘Q** i uruchom go ponownie, aby przeładować wszystkie sesje MCP.
