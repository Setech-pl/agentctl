# agentctl 0.27.0

- MCP `set_limits` submits a two-hour request for the owner by default. The owner gets a desktop notification and a WALL decision-request. Use board `L` or `agentctl limits approve ID` / `reject ID` to decide. Timed provider holds continue to apply directly.
- Chat quotas follow the global caps using percentages and the configured overprovision multiplier. Keep absolute overrides for individual providers when migrating from 0.25.
- Switch profiles with `agentctl limits profile night` or from the board. A daily schedule uses local times and an IANA timezone. `limits set claude=10 --until 23:00` expires back to the active profile.
- Applied settings changes publish old and new values, their source and effective chat ceilings on WALL `agentctl`.

[Limits for several chats and migration](../en/tutorial.md#limits-for-several-chats)

Upgrade a clone installation once the release tag is available in that clone.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.27.0
agentctl doctor
```
