# agentctl 0.26.0

- `setup: {from_task: NC-42}` clones a compatible local task's dependencies with copy-on-write. The review keeps its own worktree and uses ordinary setup if the clone is unavailable.
- `review: {mode: readonly-on-author}` opens a review in a stopped author's local checkout. Task-scoped Git hooks refuse ordinary commits and pushes, and evidence goes under the cache.
- `merge_base_check: warn`, `block`, or `candidate` checks review freshness against local `main` or `master`. Candidate conflicts show the affected paths and block the start.
- Watch proposes GC after local integration by posting a WALL info message with size and a request ID to each affected owning chat. Deletion requires confirmation. Set `gc: {after_integration: off}` to disable proposals.
- `close` marks a task closed even after its window disappears, and recognizes the exact ID of an already closed task.

[Reviews and integrations without filling the disk](../en/tutorial.md#reviews-and-integrations-without-filling-the-disk)

Upgrade a clone installation once the release tag is available in that clone.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.26.0
agentctl doctor
```
