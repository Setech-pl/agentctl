# agentctl 0.25.1

- Watch claims plan alerts in shared state before sending them to the desktop or phone. Each provider, plan window, threshold and reset period gets one alert across watch restarts, brief gaps in readings and small corrections to the reset estimate.
- MCP status shows a one-line capacity change once per chat session. Watch owns quota-exhaustion alerts, and hooks still hold the affected provider immediately. Watch records trust, disk and load transitions before announcing them.

For a clone installation, upgrade after the tag is available in the source repository.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.25.1
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Quit Claude Desktop with **⌘Q** and reopen it to reload every MCP session.
