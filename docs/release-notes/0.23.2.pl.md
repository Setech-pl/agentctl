# agentctl 0.23.2

- **WALL-23** naprawia rejestrowanie wiadomości przez MCP `send` już przy pierwszym wywołaniu. Podgląd pokazuje dokładny tekst, stan okna oraz zawartość pola wpisywania, jeśli jest czytelna. Jeśli przy wykonaniu potwierdzonego `send` agent nadal będzie zajęty, odbierze wiadomość z kolejki po zakończeniu tury. Dotyczy to zadań lokalnych i zdalnych przez SSH.
- Po sprawdzeniu podglądu przekaż `confirm: true` i zwrócony `preview_token` w tej samej sesji MCP. Dotyczy to też `send` z `withdraw` i pojedynczej oceny `mark`. `send` z `enter_only` oraz `answer` nadal sprawdzają dokładną zawartość pola lub bieżące menu.
- Narzędzie zapisu `gc` zwraca podgląd przed utworzeniem żądania. Jeśli watch ma przygotować plan zdalnego GC, użyj narzędzia odczytu `gc_preview`.
- Po aktualizacji watch odrzuca oczekujące wiadomości i oceny zapisane wcześniej bez podglądu. Jeśli są nadal potrzebne, wyświetl podgląd i potwierdź ponownie.

W instalacji z klonu uruchom:

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.23.2
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Zamknij Claude Desktop przez **⌘Q** i otwórz ponownie, aby wczytać nowy serwer MCP. Zostaw okna zadań otwarte.
