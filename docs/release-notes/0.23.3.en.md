# agentctl 0.23.3

- Watch tracks its current step in `watch-heartbeat.json` in the state directory. It logs failures and steps that exceed their deadline, skips them, and publishes a snapshot. If it cannot collect live rows or prepare the full snapshot, it publishes disk information and marks the snapshot as degraded.
- Board, MCP and doctor show watch snapshot age and the restart command after two minutes. MCP `status {capacity: true}` can use the durable queue and journal, fresh free-space counters, and capacity from the last available snapshot with its timestamp.
- Local free-space sampling has a short deadline and tries `df` if the primary probe fails or stalls. Worktree sizes can still be measuring or display an older reading.

For a clone-based installation, run:

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.23.3
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Quit Claude Desktop with **⌘Q** and reopen it to reload the MCP server. Keep the task windows open.
