# agentctl 0.23.3

- Watch zapisuje bieżący etap w pliku `watch-heartbeat.json` w katalogu stanu. Zapisuje błędy i przekroczenia limitu czasu, pomija dany etap i publikuje stan. Gdy nie uda się zebrać stanu zadań lub przygotować pełnego odczytu, publikuje dane o dysku i oznacza stan jako niepełny.
- Board, MCP i doctor pokazują wiek stanu watch i po dwóch minutach podają komendę restartu. MCP `status {capacity: true}` może pokazać zapisaną kolejkę i dziennik, świeży odczyt wolnego miejsca oraz dane o limitach z ostatniego dostępnego odczytu wraz z jego datą.
- Odczyt wolnego miejsca na dysku ma krótki limit czasu. Po błędzie lub przekroczeniu limitu następuje próba z `df`. Rozmiary worktree mogą nadal się liczyć albo pochodzić ze starszego pomiaru.

W instalacji z klona uruchom:

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.23.3
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Zamknij Claude Desktop przez **⌘Q** i uruchom ponownie, aby przeładować serwer MCP. Okna zadań mogą pozostać otwarte.
