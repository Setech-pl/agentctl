# agentctl 0.27.2

- Bramka wydania sprawdza 1500 rekordów zadań pod obciążeniem zbliżonym do produkcji i kontroluje SHA oraz pliki testowe przez cały przebieg.
- Aktualizacja klona sprawdza postęp watch, dopuszczanie zleceń, odpowiedzi MCP i nagłówek board. Nieudana kontrola przywraca poprzednią stabilną wersję z konfiguracją i wysyła właścicielowi informację na WALL.
- Polecenie `agentctl canary --from <AGENTCTL_HOME> --minutes 30` przeprowadza próbę na oczyszczonej kopii stanu przed aktualizacją.
- Watch daje pierwszeństwo wielokrotnie pomijanym etapom i wznawia zablokowaną pętlę. Ponawia weryfikację znikniętych okien i przejściowe błędy CLI, wykrywa gotowy raport przy bezczynnym oknie oraz odnotowuje zależności bez werdyktu i niejasne werdykty.
- Podgląd kolejki wskazuje woluminy worktree. Stan i cache mają osobny próg 5 GiB. Można usuwać kwoty czatów i zapisywać odroczone kontrole w raporcie. Nieaktualne odczyty planów pokazują n/d.
- Domyślnie wysokie obciążenie zgłasza alert. Aby powyżej `capacity.load_threshold` wstrzymać starty, ustaw `queue.hold_on_load: true`. Kolejka pokaże powód.
- Watch ponawia start w tle z limitami czasu poleceń. Przerwany start ze starszej wersji wymaga jawnego `agentctl resume TASK`.
- Zawiera poprawkę produkcyjną 0.26.1 z limitami czasu checkoutu i setupu, odzyskiwaniem blokad i przerwanych startów, nadzorowanym restartem watch oraz trybami usuwania w GC.
- Po aktualizacji zamknij wszystkie czaty Claude przez ⌘Q i otwórz je ponownie. Serwery MCP sprzed 0.27 nie mogą zmieniać limitów. Przed ręcznym powrotem uruchom `agentctl config downgrade-check --to 0.26.x`.
