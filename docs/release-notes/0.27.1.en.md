# agentctl 0.27.1

- Watch saves the exit code and the last 20 lines available from a vanished task window. Status and the journal show the log path. Watch retries once in the original worktree if the prompt was unconfirmed or the process exited during `launch.grace_s` (120 seconds by default). After a second early exit, look for `launch-failed`. Use `agentctl resume TASK` to preview and reopen the task under the existing ID. Dependents name the dead or cancelled prerequisite.
- CLI and MCP resolve exact task or queue IDs before prefixes. MCP `task_spec` also opens the queued spec when the task has yet to start.
- Status, events, capacity, limits and the board agree on active tasks and unread reports. Lists with task counts show up to five IDs. Capacity says which report windows would free a slot when closed. Expired provider readings display their age once the reset or age limit is reached.
- Watch records `WSTRZYMANE` once per registered order held by load, disk, quotas or another admission constraint. The queue and status name the reason. `agentctl limits reserve claude=1 --until 21:30` sets an expiry for that provider’s reservation. Capacity and status show active reservations.
- Call `events_since` with `as: chat:<name>` to see that chat’s tasks, cohorts and WALL subscriptions with one count of other chats’ events. Use `all: true` to include other chats’ task and cohort events. The same identity adds effective quota and global headroom to capacity, limits and status.
- `agentctl gc --keep A,B C --force-dirty D` counts protected worktrees under **Skipped (pinned)**. GC previews include clean dead worktrees with zero commits over their base. GC completion events show how many worktrees were removed, how many records were archived and the GiB reclaimed.

Upgrade a clone installation once the release tag is available in that clone.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.27.1
agentctl doctor
```
