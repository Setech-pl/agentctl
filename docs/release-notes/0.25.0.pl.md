# agentctl 0.25.0

- Jedna instancja obsługuje kilka czatów WALL z własnymi kwotami dla dostawców. Kolejka daje pierwszeństwo zadaniom poniżej minimum czatu, a potem najniższemu wykorzystaniu kwoty. Limity globalne obejmują zadania lokalne i na hostach SSH.
- Zlecenia MCP zachowują tożsamość czatu. Status, board i kolejka wskazują właściciela i powód oczekiwania. Limity i pojemność pokazują liczniki globalne oraz liczniki czatów.
- Właściciel może zmieniać kwoty przez CLI lub MCP. Opcjonalna samoobsługa pozwala czatowi zmieniać własne kwoty w ramach budżetu. Zmiany trafiają do zdarzeń i na WALL.

Bez sekcji `quotas:` kolejka działa po staremu. Współdzieloną instancję skonfigurujesz według [samouczka](../pl/tutorial.md#kilka-czatów-na-jednej-instancji). Po włączeniu kwot starsze zadania bez właściciela korzystają z kwoty domyślnej.

W instalacji z klona uruchom polecenia po udostępnieniu taga w repozytorium źródłowym.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.25.0
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Zamknij Claude Desktop przez **⌘Q** i uruchom ponownie, aby przeładować MCP.
