# agentctl 0.25.0

- One dispatcher can serve several WALL chats with independent provider ceilings. The queue fills eligible chat floors first, then favors the lowest share usage. Global limits still apply across local and SSH tasks.
- MCP orders preserve the chat identity. Status, board and queue explain who owns work and which quota a queued task is waiting for. Limits and capacity show the global and chat counts.
- The owner can edit quotas in CLI or MCP. Optional self-service lets a chat edit its own shares within the overprovision budget. Applied changes appear in events and on WALL.

To migrate, leave `quotas:` absent for the previous scheduling behavior, or follow the [shared instance tutorial](../en/tutorial.md#several-chats-on-one-instance). Older ownerless tasks use the default share once quotas are enabled.

For a clone installation, run after the tag is available in your source repository.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.25.0
agentctl watch --tmux --restart
agentctl board --tmux --restart
agentctl doctor
```

Quit Claude Desktop with **⌘Q** and reopen it to reload MCP.
