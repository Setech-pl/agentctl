# agentctl 0.27.3

Jeden dyspozytor na Macu zleca pracę także na komputerze Windows z Ubuntu WSL. Automatyczny wybór hosta respektuje limity, powiązane worktree i rezerwacje właściciela. Gałęzie wracają na Maca przez Git fetch. Wyłączne zadania perf przesyłają build na PC i wyniki pomiarów na Maca. Zobacz [instrukcję dla dwóch maszyn](../pl/hosts.md#dwie-maszyny-mac--pcwsl).

- **Wybór hosta zdalnego.** Zlecaj z `host: auto` albo kieruj czaty i kohorty przez `placement.chats` / `placement.cohorts`. Wybór sprawdza miejsce na koncie, limity hosta, klon repozytorium, logowanie CLI, próbkę stanu z ostatniej minuty, wolumin roboczy, obciążenie i dostępność. Pierwszeństwo mają powiązane worktree, potem host z mniejszą liczbą zadań i kolejność `placement.prefer`. Niedostępny, a uprawniony host wstrzymuje start lokalny na czas `placement.failover_after`.
- **Powrót gałęzi.** Watch pobiera gałąź zadania z hosta do klonu na Macu po raporcie i przy zamknięciu. Gałąź wyciągnięta lub rozbieżna zachowuje lokalną referencję, głowica hosta zostaje w `refs/remotes/<host>/<branch>`, a dziennik odnotowuje konflikt. `sync: off` wyłącza synchronizację.
- **Dostępność PC.** `hosts.<nazwa>.availability` rezerwuje maszynę według okien czasowych (także przez północ), zajętych procesów lub obciążenia GPU, z `yield: stop-new` albo `pause-all`. `agentctl hosts pause pc --until 3h` i `agentctl hosts resume pc` (MCP `hosts_pause` / `hosts_resume`, klawisz `H` na tablicy) ustawiają rezerwację ręczną.
- **Perf na hoście.** `class: perf` rezerwuje host na wyłączność o zaplanowanej porze, przesyła na niego build z limitem rozmiaru i odsyła wyniki pomiarów.
- Zawiera wszystkie zmiany z 0.27.2.

**Uwaga przy aktualizacji:** nic nie przenosi się na PC samo. `placement.default` pozostaje `local`, dopóki go nie skonfigurujesz; bez `host:` w specyfikacji i bez pasującej reguły `placement` zadania nadal działają na Macu. O wstrzymaniu startów lokalnych przy obciążeniu nadal decyduje `queue.hold_on_load`.

Zaktualizuj instalację z klonu, gdy tag wydania jest już w tym klonie.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.27.3
agentctl doctor
```
