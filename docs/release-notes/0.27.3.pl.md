# agentctl 0.27.3

Jeden dyspozytor na Macu zleca pracę także na komputerze Windows z Ubuntu WSL. Automatyczny wybór hosta respektuje limity, powiązane worktree i rezerwacje właściciela. Gałęzie wracają na Maca przez Git fetch. Wyłączne zadania perf przesyłają build na PC i wyniki pomiarów na Maca. Zobacz [instrukcję dla dwóch maszyn](../pl/hosts.md#dwie-maszyny-mac--pcwsl).
