# agentctl 0.27.1

- Watch zapisuje kod wyjścia i do 20 ostatnich dostępnych wierszy okna zadania. Status i dziennik podają ścieżkę logu. Watch ponawia start raz w tym samym worktree, jeśli dostarczenie polecenia nie zostało potwierdzone lub proces zakończył się w czasie `launch.grace_s` (domyślnie 120 sekund). Druga wczesna awaria kończy się zdarzeniem `launch-failed`. Polecenie `agentctl resume ZADANIE` pokazuje podgląd i pozwala wznowić zadanie pod tym samym ID. Zadania zależne wskazują martwe lub anulowane zadanie, na które czekają.
- CLI i MCP najpierw szukają dokładnego ID zadania lub wpisu kolejki. MCP `task_spec` pokazuje również specyfikację zadania, które jeszcze nie wystartowało.
- Status, zdarzenia, pojemność, limity i tablica pokazują zgodne listy aktywnych zadań oraz raportów do pobrania. Liczniki podają do pięciu identyfikatorów. Widok pojemności wskazuje, które okna z raportami zwolnią miejsce po zamknięciu. Odczyt po resecie lub po upływie limitu wieku pokazuje swój wiek.
- Watch zapisuje `WSTRZYMANE` raz dla zarejestrowanego zlecenia, które czeka z powodu obciążenia, dysku, limitu lub innego warunku startu. Kolejka i status podają przyczynę. `agentctl limits reserve claude=1 --until 21:30` ustawia godzinę wygaśnięcia rezerwacji dostawcy. Pojemność i status pokazują aktywne rezerwacje.
- `events_since` z `as: chat:<nazwa>` pokazuje zadania, kohorty i subskrypcje WALL tego czatu oraz jedną liczbę zdarzeń innych czatów. `all: true` przywraca zdarzenia zadań i kohort innych czatów. Ta sama tożsamość dodaje własną kwotę i wolne miejsca globalne do widoków pojemności, limitów i statusu.
- Przy `agentctl gc --keep A,B C --force-dirty D` chronione worktree trafiają do **Skipped (pinned)**. Podgląd GC uwzględnia czyste worktree martwych zadań bez commitów ponad bazę. Zdarzenie końcowe GC podaje liczbę usuniętych worktree, zarchiwizowanych wpisów i odzyskane GiB.

Zaktualizuj instalację z klonu, gdy tag wydania jest dostępny w tym klonie.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.27.1
agentctl doctor
```
