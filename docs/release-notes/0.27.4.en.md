# agentctl 0.27.4

Field fixes from daily work with automatic GC, the board, the watch journal and events, merged with the 0.27.3 Mac dispatcher / PC worker release and the 0.26.5 read/close fast path.

- **Automatic GC.** A dry-run inventory resumes after its deadline instead of starting over; unchanged WALL plans repeat only after `disk.auto_gc.report_every` (12h by default); skipped categories and pinned tasks show their cached sizes; a paused plan survives a temporarily unavailable free-space reading or a different mount alias.
- **Board.** Down reaches the pulled-report groups, End or G jumps to the last selectable row, and D opens the GC preview.
- **Watch journal.** Observed transitions are checkpointed before publication and replayed after a skipped journal stage or a watch restart; a prompt delivery failure is journaled once; cohort completion notices see the latest task move. A remote needs-trust entry still carries the SSH attach command.
- **Events.** `events_since` counts ready reports from task files and status together and names every unpulled report within the response budget, matching the board.
- **Configuration.** Board, limits and doctor show when a config edit was rejected and which version stays loaded; MCP responses flag a server older than watch.
- **0.26.5 read/close fast path.** `get_report`, `pull_ready` and `list_reports` read task files directly; exact-ID `close`/`cancel` previews skip status collection; contended acknowledgements wait for watch; `mcp.response_budget_s` (default 8, maximum 50; 25 recommended under load).
- Includes everything in 0.27.3, 0.26.5 and the 0.26.3/0.26.4 fixes.

Upgrade a clone installation once the release tag is available in that clone. Quit and reopen Claude (⌘Q) so the MCP server matches watch.

```sh
cd ~
~/Projects/agentctl/bin/agentctl-update --ref v0.27.4
agentctl doctor
```
