# Standing agent rules

- The first shell command must export `AGENTCTL_LIVE_CACHE` to the absolute task directory given in the prompt. Keep all task-owned scratch, builds, caches and evidence there; fail closed if it is missing. At the end remove disposable files, keep reports/logs and bounded JSON/final PNG evidence (at most 200 MB), stop owned processes and release ports. Retain worktree `node_modules` and shared runtimes. Report task cache and worktree `.cache` size before/after cleanup (`du -sh`) and disk space (`df -h /System/Volumes/Data`).
- Never push, open a PR, tag, publish, run `npm link` or `agentctl-update`, or rewrite history. Bump versions only when explicitly instructed.
- Never touch `~/.agentctl`, `~/.agentctl-dev`, `~/Projects/cache/agentctl-p19`, or other worktrees. Never run real Claude, Codex or Kimi inference unless the prompt explicitly allows it.
- Run gates only through `npm run gate -- <tier>`: fixes/features use `quick`; integration merges use `full`; release candidates use `release`. Reviewers use `quick` and do not repeat a gate already recorded PASS for the same SHA. Check that the recorded scope matches (including dirty state and skipped live checks). Never build custom runners.
- Never wait for machine load. Gates use `nice -n 10` and, on macOS, `taskpolicy -b`; full/release wait only for the shared gate lock. Prefer deterministic assertions over wall-clock assertions.
- Branch from the integration tip named in the prompt. Make one commit per item. Record changes under CHANGELOG `[Unreleased]`. Document user-visible behavior in English and Polish; preserve the product language.
- Write the report in English, at most about 3 KB. Its first line must literally be `Werdykt: PASS` or `Werdykt: FAIL`. Include commits, one line per gate, deviations, not covered, and exactly one fenced `agentctl-outputs` YAML block (`version: 1`, repository `agentctl`, existing branch names and full SHAs). Keep evidence files next to the report; collapse SKIP lists to one line. End the report and the final terminal message with a 3–6 sentence summary in Polish for Marcin. Follow any attempt marker/report-end protocol in the prompt.
